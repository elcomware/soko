# Storefront editor checklist

Compact summary per placement with named selection strategy, eligibility, category and product limit. Right/bottom responsive shared drawer stages placement changes; Apply changes the draft, not the live storefront. Validate manual duplicate/missing/ineligible pins. Semantic DOM section ordering and keyboard Up/Down controls remain intact. Publish is explicit; navigation/discard confirmation and pending-save locks prevent accidental loss. Submitted/authoritative snapshots prevent false saved status after latency edits. Actor-scoped browser history recovers the full unpublished configuration after Back; no claim that popstate is blocked. Exact authorized navigation entry gates recovery. Version remains attached to recovered drafts, allowing server conflict checks.
